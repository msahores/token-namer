Token Namer

Build the name of a primitive or semantic token, choosing one value per slot.

How to read this tool. A token has two layers. The primitive names a value of the catalog without saying what it is for (color-blue-500). The semantic names a usage decision and points to a primitive (color-background-danger-hovered). The name is built with slots in a fixed order; only the ones needed are used.

Three rules that live in no slot: the brand and the light/dark mode change the value, never the name. A valid name does not mean the token exists: it is created when something uses it. And the options loaded here are a frontend draft for discussion, not the team's closed grammar. Primitive scales follow what was agreed with design in September 2026; the semantic vocabulary is the next iteration.

Optional. Example: the background of destructive buttons. This app exists to name decisions, not to generate names.
